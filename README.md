# AI in Water

A data-science learning project for water management, tailored for students and water engineers attending an AI summer school.

## What this repo is for
- Explore water-related datasets with Python notebooks
- Practice data cleaning, visualization, and machine learning
- Build reproducible analysis workflows for teaching and workshops

## Suggested structure
- docs/ — notes, slides, and lesson material
- data/ — original datasets
- utilities/ — reusable analysis and modeling code
- notebooks/ — hands-on teaching notebooks and exercises

## Quick start
1. Create the environment with `uv sync --all-extras`
2. Start Jupyter Lab with `uv run jupyter lab`
3. Open the notebooks in `notebooks/` and begin exploring

## Summer-school focus
This repo is designed to support a practical, notebook-first data science experience for learners who want to apply AI methods to water management problems.
